# Third Wave BBQ Exercise Brief

This file preserves the exercise brief provided for the Graduate Software Developer, AI & Automation application.

## Scenario

Third Wave BBQ has an existing web application used by Head Office and multiple restaurant locations. It uses:

- Next.js for the frontend
- NestJS for the backend
- PostgreSQL for the database
- Docker Compose
- An Ubuntu VPS

The requested feature is a maintenance and operational issues feature. A venue manager should be able to:

- Create an issue
- Add a description and photographs
- Select a priority
- Assign the issue to another user
- Set a due date
- Update its status
- Add comments

Venue employees must only be able to see issues belonging to their own venue. Head Office employees must be able to see issues across all venues. Overdue issues should generate a daily email reminder.

## Required Response Sections

1. Requirements
2. Development plan
3. Instructions to the AI coding agent
4. Reviewing AI-generated work
5. Code review
6. Deployment
7. Production problem
8. Previous project
9. AI usage disclosure

The response should be no more than approximately 1,200 words.
