# Third Wave BBQ - AI Development Exercise

This repository contains my response to the Third Wave BBQ Graduate Software Developer, AI & Automation exercise.

The exercise asks for a written technical response, not a full implementation. The documents explain how I would clarify requirements, plan development, guide an AI coding agent, review generated work, deploy safely and respond to production issues.
